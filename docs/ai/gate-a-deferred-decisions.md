# AI Gate A Deferred Decisions

The following decisions are explicitly deferred beyond Gate A:

- external AI provider, model family, hosting region, and failover strategy;
- provider API key creation, rotation, storage, and incident response;
- retrieval source list beyond read-only public REZNO policy/catalog contracts;
- embedding or vector storage design;
- streaming UI, chat history, memory, personalization, and summarization retention;
- any customer, business, or admin action execution;
- ranking or recommendation quality thresholds;
- pricing, token, and usage billing controls beyond the Gate A zero-cost contract;
- production rollout, monitoring, alerting, rate limits, and abuse response;
- Gate B, Gate C, and Gate D implementation details.

Gate B is not started by this work. Migration 52 is not created.
